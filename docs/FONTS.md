# Fonts

The app serves its display fonts locally from `frontend/public/fonts/`; no font
is fetched from a third-party CDN at runtime.

## Literata

- Files: `Literata-Variable.ttf`, `Literata-Italic-Variable.ttf`
- Project: [Literata](https://github.com/googlefonts/literata)
- License: SIL Open Font License 1.1

The variable font provides optical-size and weight axes. The browser selects the
appropriate optical size and weight automatically.

## Source Han Serif SC

- Files: `SourceHanSerifSC-Regular.otf`, `SourceHanSerifSC-Bold.otf`
- Project: [Adobe Source Han Serif](https://github.com/adobe-fonts/source-han-serif)
- License: SIL Open Font License 1.1

The OFL permits redistribution and embedding. Keep the license notices with any
public distribution.
